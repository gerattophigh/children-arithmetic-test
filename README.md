# 儿童算术小测试

一个纯 HTML、CSS、JavaScript 的儿童加减法与乘法口诀学习工具。无需安装依赖，可直接在浏览器中运行，并通过 GitHub Actions 自动部署到 GitHub Pages。

## 功能

- 普通加减法测试可选择 20、50、100 题，默认 100 题
- 首页新增“做题记录”入口
- 每次交卷后自动保存完成日期和时间、测试类型、题数、用时、正确题数和成绩
- 做题记录按最新优先展示，最多保留最近 100 次
- 普通测试、错题集和乘法口诀测试都会写入记录
- 首页新增同级“乘法口诀表”入口
- 乘法口诀支持选择 1–9，默认展示 5 的口诀
- 同时显示算式和中文口诀，例如 `1 × 5 = 5` / “一五得五”、`2 × 5 = 10` / “二五一十”
- 每组口诀可直接开始 9 道乘法测试
- 乘法测试支持四选一、手动输入、自动下一题、计时、暂停、重来、评分和错题回顾
- 乘法测试的首次用时和正误也会写入学习记录
- 首页新增“错题集 / 专项练习”入口，可一键开始
- 专项集默认练习“小数 + 大数 = 6、7、8、9”
- 覆盖 12 种组合：`1+5`、`2+4`、`1+6`、`2+5`、`3+4`、`1+7`、`2+6`、`3+5`、`1+8`、`2+7`、`3+6`、`4+5`
- 每种专项题练两遍，共 24 题，题目和选项随机打乱
- 加法、减法、加减混合三种模式
- 10 以内、100 以内两种范围
- 顶部计时器
- 暂停、继续和重新开始
- 答题页、成绩页均可返回首页
- 每题提供 A/B/C/D 四个选项
- 点击选项后自动进入下一题
- 支持直接输入答案，按 Enter 进入下一题
- 自动记录每道题首次作答时间和正确情况
- 自适应出题：薄弱题型提高出现概率，熟练题型降低出现概率
- 同时识别具体题目、相邻题目和题型家族，例如 `2+5`、`2+4`、`2+几`
- 100 以内额外识别进位加法和退位减法
- 学习记录保存在当前浏览器的 `localStorage` 中
- 提交后自动评分、生成学习分析并展示错题
- 手机、平板和电脑自适应

## 题目数量与做题记录

普通加减法测试可在首页选择 20、50 或 100 题，选好题型和范围后再开始答题。错题集仍为 24 题，单组乘法口诀测试仍为 9 题。

每次完成测试并提交后，系统会自动保存：

- 完成日期和具体时间
- 测试类型与题数
- 完成用时
- 答对题数
- 百分制成绩

点击首页的“查看做题记录”即可查看，最新记录排在最上方，最多保留最近 100 次。记录保存在当前设备、当前浏览器的 `localStorage` 中；清理浏览器数据或更换设备后，记录不会自动同步。

## 乘法口诀表与测试

首页的“打开乘法口诀”与普通测试、错题集处于同一级。进入后可选择 1–9 中的任意数字，页面会展示对应的 9 条算式和规范中文口诀，并默认打开“5 的口诀”。

读完口诀后，点击“测试 N 的口诀”即可开始 9 道题。题目顺序和四个答案选项会随机打乱，测试成绩、错题、首次作答时间和正误会进入原有学习记录。

## 错题集 / 专项练习

首页的“直接开始错题集”按钮会跳过普通题型设置，直接开始 24 道专项题。专项模式完整支持四选一、手动输入、选项自动下一题、计时、暂停、重来、返回首页、提交评分和错题回顾。

专项练习与普通测试共用同一套学习记录：每道题的首次作答时间和正误都会写入当前浏览器的自适应学习档案，因此之后的智能出题也会参考这些表现。

## 本地运行

直接双击 `index.html` 即可打开。

## 使用 GitHub Actions 部署到 Pages

### 第一次设置

1. 在 GitHub 新建仓库，建议使用公开仓库。
2. 将本项目中的全部文件上传到仓库根目录，必须保留 `.github/workflows/deploy-pages.yml` 的目录结构。
3. 确认默认分支名称为 `main`。如果你的分支不是 `main`，请修改工作流文件中的分支名称。
4. 打开仓库的 `Settings` → `Pages`。
5. 在 `Build and deployment` 的 `Source` 中选择 **GitHub Actions**。
6. 返回仓库的 `Actions` 页面，等待 `Deploy GitHub Pages` 工作流运行完成。
7. 部署成功后，可在 `Settings` → `Pages` 或该次工作流的部署信息中找到访问地址。

### 后续自动更新

以后只要修改文件并推送到 `main` 分支，GitHub Actions 就会自动重新部署，无需再次设置 Pages。

也可以进入 `Actions` → `Deploy GitHub Pages`，点击 `Run workflow` 手动部署。

## 工作流说明

工作流会依次执行：

1. 检出仓库代码
2. 将 `index.html` 复制到临时发布目录 `_site`
3. 配置 GitHub Pages
4. 上传 Pages artifact
5. 部署到 `github-pages` 环境

本项目是纯静态网页，不需要 Node.js、npm 或其他构建工具。

## 学习记录说明

系统综合使用正确率、首次作答用时、具体题目表现、相邻题目表现和同类题型表现调整后续出题概率。

答错的权重高于答得慢。熟练题不会完全消失，只会降低出现频率，以保留复习和遗忘检测。

学习记录只保存在当前设备、当前浏览器中。清理浏览器数据或更换设备后，记录不会自动同步。
